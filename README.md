# Automated Curriculum Design Using LLMs

**Team 32** — B. Hansika Reddy, P. Shravani Mudhiraj, Tashifa Nooreen
**Guide:** Mr. N.S.S.S. Girish Kumar, Assistant Professor
**Department:** CSE (AI&ML), Vardhaman College of Engineering

## Problem Statement
Designing an effective curriculum is a complex, time-consuming manual process. This project leverages LLMs to automatically generate structured, adaptive curricula based on course objectives, learner proficiency, and industry skill demand.

## Architecture
Three core modules:
- **M1 — Learner Proficiency Estimation** (knowledge tracing)
- **M2 — LLM-Driven Curriculum Synthesis Engine**
- **M3 — Industry Skill Intelligence Module**
